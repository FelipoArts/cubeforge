O Windows pode mostrar um aviso — é normal

Como o Cubicase é um projeto novo e pequeno, o Windows Defender SmartScreen às vezes exibe "O Windows protegeu seu PC" no primeiro clique. Basta clicar em "Mais informações" e depois em "Executar assim mesmo". O código-fonte é aberto e público no GitHub, se quiser conferir.

Depois de baixar

Três passos até o primeiro mundo

1

Execute o instalador

Dois cliques e o Cubicase já está instalado — nada de configurar nada nessa etapa.

2

Abra o Cubicase

Escolha "Criar servidor", a versão do Minecraft e, se quiser, um mod loader.

3

Chame a galera

Copie o código do servidor e mande pros seus amigos entrarem pelo Cubicase deles.
