Windows may show a warning — that's normal

Since Cubicase is a new, small project, Windows Defender SmartScreen sometimes shows "Windows protected your PC" on the first click. Just click "More info" and then "Run anyway". The source code is open and public on GitHub, if you want to check it.

After downloading

Three steps to your first world

1

Run the installer

Two clicks and Cubicase is installed — nothing to configure at this stage.

2

Open Cubicase

Choose "Create server", the Minecraft version and, if you want, a mod loader.

3

Invite the crew

Copy the server code and send it to your friends so they can join through their Cubicase.
